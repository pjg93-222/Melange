## Format conventions

- Every workbook has the sheets `data`, `dictionary`, `sources`, `coverage`; extra table sheets are named above. The crosswalk's `coverage` shows which mapping fields are filled.
- Header in row 1, one table per sheet, values only: no formulas, merged cells, styles, colours, comments, filters or frozen panes.
- Missing is an empty cell, never 0. A zero appears only where the source states zero.
- Each table sheet has a `status` column: observed / partial / missing / not_applicable (`current_control` also uses `derived` for 2026); the crosswalk's status is `per plan of 2026-09-25 15:22`.
- Dates are ISO text YYYY-MM-DD, months YYYY-MM; years are integers.
- Money: `<name>_nominal_usd` and `<name>_real_2025_usd` = nominal x `multiplier_to_2025_dollars` for the calendar year from `cpi_annual_2006_2025.csv`. IBISWorld revenue is already in constant dollars (2026 for the original sectors, 2024 for the added series) and is not CPI-converted.
- Every table row has `source_id`, which points to a row of the `sources` sheet (absolute path, ZIP member, SHA-256, size, mtime, rows read, read time).
- The lobbying data is used as it stands: nothing is reclassified, filtered or deduplicated.
