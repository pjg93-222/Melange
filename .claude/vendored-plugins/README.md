# Vendored Claude Code plugins

This folder is a snapshot of Paul's installed Claude Code plugins taken on 2026-10-02, vendored here for reference. It was copied from `C:\Users\pgoff\.claude\plugins` and includes `cache\`, `.install-manifests\`, `synced\`, `installed_plugins.json` and `known_marketplaces.json`.

The `node_modules` folders, the `marketplaces` catalog clones and the `data` folder were excluded. They are reinstallable and can be recreated by reinstalling the plugins or re-adding the marketplaces. Files larger than 50 MB were also skipped.

This folder is not auto-loaded by Claude Code. Claude Code reads plugins from `~\.claude\plugins`, not from this repository, so nothing here changes the behaviour of any session.
