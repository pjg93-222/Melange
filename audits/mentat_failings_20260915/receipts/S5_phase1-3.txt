6. WHAT THE CODE CONTRADICTED IN S5_DESIGN.md
--------------------------------------------------------------------------------
a. Section 0.5 says #graph-candidate-controls is "hidden until candidates load".
   It is not. graph.js applyAnalysis() set
   `get('candidate-controls').hidden = analysis !== 'candidates'`, so the Candidate
   view select was reachable only from the Candidates analysis tab, at any time.
   Removing `hidden` from index.html alone would have been undone by applyAnalysis()
   on the next call. Built per the brief's own instruction for that case: the rule
   now lives in graph.js and reads "visible wherever the candidate panel is showing,
   once a report is chosen"; index.html:105 keeps its `hidden` for the moment before
   a report exists.
b. Section 4 says "server.py: untouched". See section 5 above.
c. Section 4 says app.js's showView should call MentatScope.write({}) after
   switching. Not built: write({}) changes nothing, so it dispatches nothing (the
   module is a no-op on an unchanged URL by contract), and no listener needs it -
