SHARES ARE LAND AREA, and that is forced by the source, not chosen: the relationship file's
header is OID/GEOID/NAMELSAD/AREALAND/AREAWATER/MTFCC/FUNCSTAT for the CD, the same seven
for the ZCTA, then AREALAND_PART and AREAWATER_PART. There is no population column at all.
Shares are computed as AREALAND_PART / sum over the ZCTA's parts, parts under 0.01 dropped,
the rest renormalised, rounded to 3 decimals with the residual folded into the largest part
so every ZCTA sums to exactly 1.000 (verified for all 33,791 in both files).

   them would have lost money: their FIPS codes are resolved from a documented four-entry
   table, their ZIPs keep keys AS-AL/GU-AL/MP-AL/VI-AL, and each vintage file lists them
   under "undrawn" with the reason. district_exists() counts them as real seats. Before this,

   git status --untracked-files=all, which now lists all six JSON files as untracked. Say
   the word and it can be dropped in favour of `git add -f`, which is how the receipts in

5. THE FEC CANDIDATE MASTER CARRIES SEATS THAT DO NOT EXIST, and they are passed through,
   not dropped. Districts as filed include TX-66 and FL-81 (cn22), MT-22 and FL-59 (cn26) -
   no such seats. district_for_candidate returns the key exactly as the master states it and
   district_exists(key, cycle) says whether the cycle's map has that seat, so the S8 caller
   can bucket them as unmatched (S6_DESIGN's rule: never dropped). Measured against the
   119th map: cn22 172 rows on 111 such keys, cn24 90 rows on 50, cn26 60 rows on 45. Most
   are honest vintage effects (PA-18, CA-53, MI-14, MT-AL: seats that existed on an older
   map), which resolve correctly once checked against the right vintage.

6. ONE CODE TRANSLATION was added deliberately. The two masters disagree on the delegate
   seats: Census writes CD..FP 98 (key *-AL) while the FEC writes district 00 for DC, PR,
   AS, GU and VI but 01 for the Northern Marianas (7 rows across the three cn files).
   Because those six jurisdictions have exactly one seat by statute, any district code there
   folds to AL. Without it those 7 rows resolved to MP-01, which no map has, and the
   delegate's money would have sat in the unmatched bucket for no reason. A blank district
   in a single-seat state (3 rows: AK, DE, GU) still returns None - the master did not say,
   and this module does not guess.
