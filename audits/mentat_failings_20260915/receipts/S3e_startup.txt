## Changes
server.py
- report_freshness / worksheet_data / stamp (report_insights), graph_schema / graph_view (graph_data), and
  comparison_subjects / comparison_flows (comparison_data) are lazy wrappers: the module is imported on first call;
  the names remain module attributes, so tests that patch.object(app, ...) still work (test_report_directory_console
  passes).
- GIT_SHA at import replaced by git_sha_cached() (lru_cache), so the git subprocess runs on the first health call.
Start-MentatApp.ps1
- Get-MentatHealth: HttpWebRequest with Proxy = $null and a millisecond timeout, replacing Invoke-RestMethod in the
  port scan and the startup poll.
- Get-MentatListeningPorts: one IPGlobalProperties.GetActiveTcpListeners() census replaces a bind probe per port;
  the first free candidate gets one confirming bind probe. Falls back to the old per-port probes if the census fails.
- The separate Python process that checked for openpyxl is replaced by a Test-Path of Lib\site-packages\openpyxl
  beside the interpreter; the process check remains as the fallback when that folder is not found.
- Edge app window flags add --disable-extensions --disable-sync --disable-background-networking
  --disable-component-update (the Mentat\browser profile is Mentat's own; extension renderers were observed in it).
