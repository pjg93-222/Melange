## 3. Copy, hash, and manifest all inputs

```powershell
& python -B fec\leg_evidence_recompute.py --copy-phase --live-root $Live --data-root $Data --out $Out
if ($LASTEXITCODE -ne 0) { throw "copy phase failed with exit $LASTEXITCODE" }

$ManifestPath = Join-Path $Out 'source_manifest.json'
$Manifest = Get-Content -Raw -LiteralPath $ManifestPath | ConvertFrom-Json
if ($Manifest.schema -ne 'legfix2-source-manifest-v1') { throw "Unexpected manifest schema: $($Manifest.schema)" }
if ($Manifest.input_count -ne 20) { throw "Expected 20 manifest entries; got $($Manifest.input_count)" }
if (@($Manifest.inputs).Count -ne 20) { throw "Expected 20 manifest input objects; got $(@($Manifest.inputs).Count)" }
```

Predicted observable result:

- 20 `COPIED <name> (<bytes> bytes)` lines, one for every fixed input.
- `WROTE ...\audits\legfix2\source_manifest.json with 20 entries`.
- Exit code 0.
- Every copy is under `$Data`; each manifest object contains `source_path`, `sha256`, `bytes`, `source_mtime`, `source_mtime_ns`, and `scratch_name`.

If any source is absent, locked/unreadable, changes while being copied, or fails copy verification, the program prints `BLOCKED: ...` and exits 2. Stop there; do not run evidence mode and do not read the live original as a fallback.

## 4. First evidence run

```powershell
& python -B fec\leg_evidence_recompute.py --data-root $Data --out $Out
if ($LASTEXITCODE -ne 0) { throw "first evidence run failed with exit $LASTEXITCODE" }

$JsonPath = Join-Path $Out 'evidence_recompute.json'
$MdPath = Join-Path $Out 'EVIDENCE_RECOMPUTE.md'
$Evidence = Get-Content -Raw -LiteralPath $JsonPath | ConvertFrom-Json
if ($Evidence.schema -ne 'legfix2-evidence-recompute-v1') { throw "Unexpected evidence schema: $($Evidence.schema)" }
if ($Evidence.summary.claim_count -ne 20) { throw "Expected E1..E20; got $($Evidence.summary.claim_count)" }
if (@($Evidence.claims.PSObject.Properties.Name).Count -ne 20) { throw 'Evidence claim map does not contain exactly 20 entries' }

$RequiredFields = @('claim','reported','recomputed','delta','verdict','method_note')
foreach ($ClaimProperty in $Evidence.claims.PSObject.Properties) {
    $ActualFields = @($ClaimProperty.Value.PSObject.Properties.Name | Sort-Object)
    $ExpectedFields = @($RequiredFields | Sort-Object)
    if (($ActualFields -join '|') -ne ($ExpectedFields -join '|')) {
        throw "$($ClaimProperty.Name) does not carry exactly the required six fields"
    }
}
```

Predicted observable result:

- 20 `VERIFIED <name>` lines before any artifact is parsed.
- `RECOMPUTE E1` through `RECOMPUTE E20`.
- Two `WROTE` lines for the JSON and Markdown pack.
- A final `CLAIMS 20; VERDICTS ...` summary.
- Exit code 0 even when a quantitative claim is `DRIFT`, an E19 aggregate is `MISMATCH`, or a locally unidentifiable rate is `NOT-RECOMPUTABLE-OFFLINE`; those are evidence findings.

## 5. Byte-determinism second run

```powershell
$BeforeManifest = (Get-FileHash -Algorithm SHA256 -LiteralPath $ManifestPath).Hash
$BeforeJson = (Get-FileHash -Algorithm SHA256 -LiteralPath $JsonPath).Hash
$BeforeMd = (Get-FileHash -Algorithm SHA256 -LiteralPath $MdPath).Hash

& python -B fec\leg_evidence_recompute.py --data-root $Data --out $Out
if ($LASTEXITCODE -ne 0) { throw "second evidence run failed with exit $LASTEXITCODE" }

$AfterManifest = (Get-FileHash -Algorithm SHA256 -LiteralPath $ManifestPath).Hash
$AfterJson = (Get-FileHash -Algorithm SHA256 -LiteralPath $JsonPath).Hash
$AfterMd = (Get-FileHash -Algorithm SHA256 -LiteralPath $MdPath).Hash

if ($BeforeManifest -ne $AfterManifest) { throw 'source_manifest.json changed during evidence mode' }
if ($BeforeJson -ne $AfterJson) { throw 'evidence_recompute.json is not byte-deterministic' }
if ($BeforeMd -ne $AfterMd) { throw 'EVIDENCE_RECOMPUTE.md is not byte-deterministic' }

[pscustomobject]@{
    ManifestSHA256 = $AfterManifest
    EvidenceJsonSHA256 = $AfterJson
    EvidenceMarkdownSHA256 = $AfterMd
} | Format-List
```

Predicted result: the second run repeats the verification/recompute lines, exits 0, all three equality assertions pass, and PowerShell prints the three stable SHA-256 values.
