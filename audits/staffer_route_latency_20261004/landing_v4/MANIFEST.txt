The pre-image of an edited file is the LIVE working file as it is now, both earlier landings applied: byte for byte landing_v3_ids's post-image for a file it edits or creates,
landing_v2's post-image for a file only landing_v2 edits or creates, and LIVE's own file for a file neither touches. apply_landing.py refuses unless every pre-image hash below matches.
Terminator profiles are live_patch.py `eol` lines (crlf = CRLF-terminated lines, lf = bare-LF lines).
verdict (worktree) = `live_patch.py drift <post-image> <branch tip file in the worktree>`: IDENTICAL_BYTES, or EOL_ONLY where the pre-image keeps its own terminators, or a new file (blob: LF) meets the worktree's git-checkout CRLF.
verdict (blob)     = the same comparison against the tip's git blob (pure LF): a new file is IDENTICAL_BYTES, an edited file EOL_ONLY wherever its pre-image is not pure LF.
