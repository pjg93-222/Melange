The More button is not on M4: it is an intended difference that keeps three existing tools reachable.
   - Row 2, under a 1px `--card-border` rule: the tabs Overview / Recipients / Candidates / Companies on the left (15px; the active tab has a 3px `--acu-gold` underline) and the three headline figures on the right, separated by thin vertical rules: "Net giving" / `#graph-total`; "Direct to candidates" / `#graph-direct` + " · " + `#graph-direct-share`; "Recipient organizations" / `#graph-recipient-count` + " · " + `#graph-organization-share`. ## Build this: the compare modes (G1-G5)

5. **Starting a comparison.** "+ Compare with..." opens a menu: "Another industry", "Another cycle", "Another company". Picking one opens a searchable list of that dimension's values (industries from the snapshot registry the Industry select uses, cycles from `#graph-cycle`, companies from `#graph-company`), without the current value. Choosing one turns the compared chip into a pill group: the current value as pill 1 (`--scope-1`), the new value as pill 2 (`--scope-2`), and a small "+" that adds a third (`--scope-3`; three at most). Each pill has a remove "×"; removing down to one pill ends the comparison. The dashed chip is replaced by the text link "Clear comparison" (`--acu-purple`, 14px). One dimension is compared at a time; choosing another kind replaces the comparison.
6. **Overline:** "Comparing industries · 2025-2026", "Banking · comparing cycles", "Banking · comparing companies · 2025-2026", or "Comparing 3 industries · 2025-2026".
7. **Headline figures** show one value per scope, stacked, each after an 8px dot in its scope colour (in company mode each line carries the pill text, shortened with the measured-fit helper on `MentatTheme` in `theme.js` when too long). Cycle mode adds a `.change-chip` after the latest value (latest against earlier).
8. **Cards with two scopes (G1-G3):** the 2x2 grid stays. Each card splits into equal halves separated by a 1px `--card-border` rule; each half starts with its `.scope-pill`. The card's Top N select still owns its rows; when a comparison starts, its default becomes 6 (add 6 to its options if absent).
   - Category cards (recipient type, employee level): every half lists the same categories in scope 1's order so rows line up; a category a scope lacks shows "—". Colours stay per category, identical across halves.
   - Ranked cards (candidates, companies): each half ranked on its own. A name present in two or more halves gets the `--tint-shared` row background in each. Cycle mode: names present in both get a `.change-chip`; names only in the latest scope get a `.new-tag` "new".
   - Company mode (G3): Company comparison does not split. It keeps one full list (Top N) with every bar `--acu-taupe` except the compared companies, drawn in their scope colours, and the footer note "Compared companies highlighted".
   - Employee level: each half has its stacked bar and legend; "By company" shows that half's first four companies (industry mode) or the same four companies aligned (cycle mode); company mode leaves it out.
   - Change chips appear only in cycle mode.
9. **Three scopes (G4):** the layout switches to stacked: cards full width, one per row, in the order recipient type, candidates, company comparison, employee level, each split into thirds. A `.segmented` "Layout: Grid | Stacked" sits at the right end of the tab row. With two scopes Grid is the default and Stacked optional; with three, Stacked is the default and Grid is disabled with the tooltip "Three scopes need the stacked layout".
10. **Drill-down tabs while comparing (G5):** Recipients, Candidates and Companies each show one card holding a sortable table: name, Party (candidates only, dot and letter), one amount column per scope with a thin inline bar under each number in the scope colour, and "Difference" (scope 1 minus scope 2, signed, `--acu-purple`; two scopes only). Above the table: filter chips with counts ("All 742", "Funded by both 214", "Only Banking 368", "Only Credit Union 160"; with three scopes "All", "In every scope" and one "Only ..." per scope), a search box ("Find a candidate", "Find a recipient", "Find a company"), the candidates' "Direct contributions" select, and one secondary "Export" at the card's top right. Clicking a header sorts (an arrow marks the sorted column; default scope 1 descending). Pager "Rows 1-10 of 214" with previous and next.
11. **Drawer (board 5):** clicking a row opens the drawer for that row's scope; in compare mode the drawer header shows that scope's pill. Nothing else in the drawer changes.
12. **URL (D-039, flat keys only):** add `compare` (`industry` | `cycle` | `company`) and `layout` (`stacked`, written only when it is not the default) to `KEYS` in `scope.js`; the compared dimension repeats its key in pill order, for example `?industry=Banking&industry=Credit+Union&compare=industry#graph`. Copy link must round-trip every compare state; add the cases to `mentat/app/tests/scope.test.js`.
13. **Data:** for each scope run the same queries the default Overview runs (from `paintAll()` and `drawPanel()`) with that scope's parameters, in parallel. Each half shows skeleton rows while its query runs; a failed scope shows an inline error in its own half and the others still render. The headline figures may come from `/api/comparison` periods only if they match the Overview's basis exactly; otherwise run the Overview's own figure query per scope. Say which you used.
14. **Motion (expressive):** when a comparison starts, the new half slides in from the right (180ms, ease-out) and its bars grow from zero; removing a scope collapses its half. Everything is instant under `prefers-reduced-motion`.
