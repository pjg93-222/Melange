# Text-C confirmatory — nail down C on the full roster (pre-registration)

**Locked 2026-07-08 BEFORE the look. Confirms the round-2 exploratory finding (Empath text -> behavioral
diligence = +0.355 party-controlled, N=90) on the FULL roster with held-out CV + confound controls.**

## Design
Full roster: **522 members** (have diligence_z + >2k chars speech text + D/R party). LINGUISTIC block =
Empath category rates (194) from each member's speech text, z-within-roster. Criterion = **diligence_z**
(behavioral C: roll-call participation + LEP follow-through + CHRG participation) — CROSS-method (text vs
voting/cosponsorship, no shared source). Ridge, repeated 5x5 CV, held-out r, exact permutation p (K>=300).
Confound block = **party + age** (age from birthday = the available seniority proxy; no tenure field
exists). NOTE: do NOT control for committee_leader / votes_cast (mediators / criterion components).

## Bars (ONE look, locked)
- **C1 (held-out signal):** Empath -> diligence held-out r **>= +0.20 AND exact perm-p < .05.**
- **C2 (confound-independent):** partial r(pred, diligence | party, age) **>= +0.15 AND p < .05**, and
  **>= 0.6x the raw held-out r** (the signal must not collapse when party+age are removed).
- **C3 (within-party robustness):** held-out prediction correlates with diligence **> 0 in BOTH** D and R.

## Outcome
- **PASS all three -> text measures C is CONFIRMED on the full roster**, party/age/seniority-independent.
  The campaign's "text can't measure C" is formally overturned (it tested a pre-built lexical-C construct
  vs votes; this tests text fit DIRECTLY to the valid behavioral criterion, Marrero/Rubio-faithful). Usable
  to score C where behavioral data is thin, and to strengthen the blended C (separate ratified wiring step).
- **MISS -> the N=90 lead does not generalize / was confound-driven; documented, C stays behavioral-only.**
